# MICHAEL SCOFIELD SMS

Plateforme de vente de numéros virtuels.

## Fonctionnalités

- Inscription / Connexion
- Achat de numéros virtuels (WhatsApp, Telegram, TikTok)
- Dépôt et validation par admin
- Historique des transactions
- Panel administrateur complet

## Comptes par défaut

- Admin : admin@ms.com / admin123
- Utilisateur : user@test.com / 123456

## Déploiement sur Vercel

1. Pousse le projet sur GitHub
2. Connecte Vercel à ton dépôt
3. Déploie automatiquement

## Technologie

- HTML / CSS / JavaScript pur
- localStorage pour le stockage
- Pas de dépendances externes
